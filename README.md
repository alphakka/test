# CutBridge 0.3 — 사진 기반 헤어 오더서

고객이 머리 관련 전문 용어를 쓰지 않아도 현재 사진과 참고 사진만으로 상담 초안을 만들 수 있게 하는 모바일 웹 MVP입니다.

## 체험
- [GitHub Pages 샘플 미리보기](https://alphakka.github.io/cutbridge/) — 실제 AI 서버 없이 **샘플 오더서**를 체험합니다.
- HTML: `index.html`
- AI 이미지 분석: `api/analyze.js`
- AI 헤어 시각화: `api/visualize.js`

## 0.3 핵심 개선
1. 사진에서 관찰한 정보와 고객 취향의 추정을 구분하며 `evidence` 표시
2. 확인 질문을 자동 선택하지 않고 고객이 직접 선택한 답만 최종 확정
3. 이미지 생성 전 변화 강도를 3단계로 선택
4. 얼굴과 배경 유지에 집중한 이미지 편집 프롬프트 개선
5. 현재 vs AI 예상 사진의 비교 슬라이더 제공
6. 샘플 모드와 실제 AI 사진 분석을 명확히 구분

## 실제 AI 사용 조건
GitHub 코드를 Vercel에 연결해 배포하고 서버 환경변수 `OPENAI_API_KEY`를 설정하세요. 선택 설정: `OPENAI_VISION_MODEL`(기본 `gpt-4o-mini`), `OPENAI_IMAGE_MODEL`(기본 `gpt-image-2`). 모델 권한·요금 확인이 필요합니다.

실제 AI 호출 시 업로드 사진은 서버를 통해 외부 API로 전송됩니다. 서비스 DB에는 저장하지 않지만 외부 제공자 보관 정책은 별개입니다. 공개 운영 전 사용 제한, 비용 제한, 동의 및 개인정보 고지, 이미지 검증 강화가 필요합니다.

AI 생성 참고 이미지는 실제 시술 결과나 완전한 얼굴 보존을 보장하지 않습니다. 미용실에서 디자이너와 최종 확인이 필요합니다.

## 검증
로컬: API 자동 테스트 9개 통과, 모바일/데스크톱 브라우저 UI 시나리오 통과, 모의 AI 이미지 생성 흐름 통과. **실제 AI 모델을 호출한 사진 편집 품질 검증은 아직 수행하지 않았습니다.**
