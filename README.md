# CutBridge — 사진 기반 AI 헤어 오더서 MVP v0.2

사진만으로도 남성 고객이 머리를 설명할 수 있도록 돕는 **모바일 우선 4단계 서비스**입니다.

## 바로 확인
- **[HTML 미리보기 (샘플 모드)](https://alphakka.github.io/cutbridge/)**
- [원본 코드](https://github.com/alphakka/test)
- [HTML](./index.html) · [AI 사진 분석](./api/analyze.js) · [AI 시각화](./api/visualize.js)

## 사용 흐름
1. 지금 머리 사진 1장 + 원하는 헤어스타일/과거 마음에 들었던 사진(선택)
2. AI가 현재와 목표의 헤어 형태를 분석해 커트 조건 자동 작성
3. 사용자에게 짧은 질문 3개만 확인
4. 최종 오더서 생성 → 복사, 공유, TXT 저장, 인쇄/PDF

사진 업로드는 브라우저에서 1024px JPG로 축소해 표시합니다.

## 샘플과 실제 AI
- **GitHub Pages 미리보기:** 실제 AI 서버를 제공하지 않습니다. **샘플 오더서 체험** 버튼으로 예시 상담을 확인할 수 있습니다. 업로드한 사진을 AI가 분석했다고 주장하지 않습니다.
- **Vercel 실제 AI 모드:** 이 저장소를 Vercel 프로젝트로 연결하고 `OPENAI_API_KEY`를 서버 환경변수에 넣어 배포합니다. `/api/analyze`에서 사진 분석, `/api/visualize`에서 참고 시뮬레이션을 제공합니다.
- 선택 환경변수: `OPENAI_VISION_MODEL` (기본 `gpt-4o-mini`), `OPENAI_IMAGE_MODEL` (기본 `gpt-image-1.5`).
- 이미지 모델 접근 권한과 API 호출 비용이 별도로 필요합니다. 이미지 시각화 API는 해당 계정에서 **실호출 검증 전**입니다.

## 프라이버시·주의사항
- 사진은 웹페이지의 저장소/DB에 저장하지 않습니다. 단 실제 AI 호출을 허용한 경우 이미지가 서버를 통해 외부 AI 제공자에 전송됩니다.
- 제3자 제공·국외 이전·서비스 제공자의 보관 정책은 운영 시 검토해야 하며 '완전 미보관'을 보장할 수 없습니다.
- 운영 공개 전에 사용자 인증, API 요금 제한, 레이트 리밋, 이미지 유효성/콘텐츠 검증, 개인 정보 보호 고지 등 보안 조치가 추가로 필요합니다.
- AI 시각화는 **예상 참고 이미지**로 실제 커트를 보장하지 않습니다.
- 단순 샘플 모드의 피드백 버튼은 저장하거나 서버에 전송하지 않습니다.

## 구현 검증
작성된 로컬 API 자동 테스트 6개가 통과했으며 프론트엔드 JS와 서버 파일을 구문 검사했습니다. 실제 클라우드 API를 통한 사진 분석·시각화는 환경변수와 공급자 권한을 설정한 후 추가 검증해야 합니다.

## 로드맵
첫 사용자 실기기 검증 → 사진 분석/시각화 실제 API 연결 → 시술 결과 기반 피드백 → 미용실 상담 공유.
