# CutBridge — AI 헤어 오더서 MVP

> 고객이 표현하는 추상적인 헤어스타일 요구를 구체적인 디자이너 상담 오더서로 변환하는 모바일 웹 MVP

## 미리보기

- **웹 미리보기(정적 데모):** https://alphakka.github.io/cutbridge/
- **원본 코드:** https://github.com/alphakka/test
- HTML 원본: `index.html`
- 선택적 서버 AI: `api/consult.js`

## 현재 구현

1. 모바일 반응형 4단계 상담
2. 남성/여성/유니섹스 커트 유형
3. 현재 헤어 사진 업로드(브라우저 내 로컬 미리보기, 외부 전송 없음)
4. 자유 입력 및 예시 문장
5. 앞머리/옆머리/윗머리 세부 옵션 선택
6. 피하고 싶은 결과와 손질 시간 기록
7. 오른쪽 실시간 헤어 오더서 요약
8. AI 서버가 연결되면 AI 상담 메모, 없으면 **규칙 기반 데모**임을 명확히 표시
9. 오더서 복사/TXT 저장/인쇄-PDF 기능

## 바로 테스트하기

`index.html`을 브라우저에서 열거나 위 미리보기 링크를 방문합니다. 기본 데모 모드만 테스트할 경우 회원 가입이나 API 키가 필요하지 않습니다.

## 실제 AI 활성화 (Vercel)

1. 해당 GitHub 저장소를 Vercel 프로젝트로 가져옵니다.
2. Framework Preset을 **Other**로 사용합니다.
3. Environment Variables에 `OPENAI_API_KEY`를 **서버 환경 변수**로 추가합니다.
4. 필요하면 `OPENAI_MODEL`을 설정합니다(기본 `gpt-4o-mini`).
5. 배포 후 프론트엔드가 동일 도메인의 `POST /api/consult`를 호출해 AI 상담 메모를 생성합니다.

GitHub Pages 미리보기는 서버 API를 실행하지 않으므로 **규칙 기반 데모 모드**로 작동합니다. 본 버전에는 AI 헤어 이미지 생성이나 얼굴형 추론 기능이 없습니다.

## 개인정보·검증 주의사항

- 사진은 브라우저 메모리에서만 미리보기로 사용하고 서버로 보내지 않습니다.
- 실제 AI 서버 활성화 시 고객이 입력한 텍스트 정보만 외부 AI 제공자에게 전달될 수 있습니다.
- 입력 정보/사진의 영구 저장 기능은 없습니다.
- 외부 공개 전에 개인정보 처리방침, API 사용 고지, 접근 제어, 속도 제한, 악용 방지 등 운영 통제가 필요합니다.
- AI가 제공하는 상담 메모는 시술 보증이 아니라 **디자이너와 협의하기 위한 초안**입니다.

## 첫 검증 가설

- 고객이 상담 내용을 3분 이내에 완성하는지
- 디자이너가 오더서가 실제 상담에 도움이 된다고 평가하는지
- '너무 짧게 자르지 않기' 같은 핵심 금지 조건이 명확히 전달되는지
- 실제 시술 후 만족도가 개선되는지
